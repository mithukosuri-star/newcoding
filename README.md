# Sonora

A local-first music player with an **original catalogue** — every track in the app was
composed, performed, and synthesized from scratch by the code in `tools/`.

## What it is

Sonora is a full streaming-style UI — home, search, library, album and artist pages,
playlists, favorites, queue, a now-playing screen, and a persistent player bar — running
entirely in the browser. There is no server, no account, and no third-party music. The
audio files are generated by the included offline synthesizer, so the whole thing is
self-contained and works offline once loaded.

Each one is arranged bar by bar: chord progressions, basslines, drum programming,
lead melodies, counter-melodies, and section structure (intro → build → main →
breakdown → finale → outro) live in `tools/render_tracks.py`.

## Features

**Playback**
- Persistent player bar with seek, volume, mute, shuffle, and repeat (off / all / one)
- Gapless-feeling queue that auto-advances, with a slide-out queue panel
- "Play next" and "Add to queue" from any track menu
- Full-screen now-playing view with a live Web Audio visualizer
- OS media-key + lock-screen integration via the Media Session API
- Keyboard shortcuts: `Space` play/pause, `←/→` seek, `↑/↓` volume, `N`/`P` next/prev,
  `S` shuffle, `R` repeat, `F` favorite, `M` mute, `Q` queue, `/` search

**Library**
- 4 mood mixes generated from track tags (Night Drive, Deep Focus, Slow Light, After Hours)
- Playlists: create, rename, delete, add/remove tracks from any row menu
- Favorites, recently played, album and artist pages
- Instant search across titles, artists, albums, genres, and moods

**Craft**
- Responsive layout from 320 px phones up to wide desktops
- Custom design system: Space Grotesk / Inter, dark theme, lime accent
- Accessible: focus rings, ARIA labels, keyboard-operable rows, reduced-motion support
- Everything you save persists in `localStorage`

## Getting started

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Regenerating the music

The audio is checked in, so this is optional. To rebuild it:

```bash
python3 -m venv .venv
.venv/bin/pip install numpy scipy soundfile lameenc

cd tools
../.venv/bin/python render_tracks.py               # all tracks
../.venv/bin/python render_tracks.py neon-drift    # just one
```

Output goes to `public/audio/*.mp3` and `src/data/tracks.generated.json`
(the app reads durations from there).

### How the synthesis works

`tools/synth.py` is a small offline DAW:

- **Oscillators** — polyBLEP anti-aliased saw/square/pulse, plus sine and triangle
- **Instruments** — supersaw pads, FM electric piano, additive bells, subtractive bass,
  808 sub bass, plucked arps, vibrato leads, breathy flutes, string sustains
- **Drums** — synthesized kick, snare, clap, hats, shaker, rim, toms, crashes, risers
- **Effects** — filters (Butterworth), chorus, tape wobble, multi-tap ping-pong delay,
  convolution reverb with generated impulse responses, beat-repeat glitching
- **Mixing** — per-bus loudness gain staging, sidechain ducking, glue saturation,
  soft limiting, and consistent loudness normalisation

`tools/render_tracks.py` contains the arrangements. `synth.Mix` renders each multitrack
session to a stereo master at 44.1 kHz and encodes it with LAME at 160 kbps.

## Project structure

```
src/
  App.tsx                  shell, routing, global shortcuts
  player/PlayerContext.tsx audio element, queue, shuffle/repeat, persistence
  nav/NavContext.tsx       simple back-stack navigation
  data/catalog.ts          index over the generated track metadata
  components/              Sidebar, TopBar, PlayerBar, NowPlaying, QueuePanel,
                           TrackRow, MediaCard, Visualizer, PlaylistPicker…
  views/                   Home, Search, Library, Favorites, Playlist, Album,
                           Artist, Mix
  styles.css               design tokens and all styling
tools/
  synth.py                 the synthesizer and mixer
  render_tracks.py         arrangements + catalog metadata
public/
  audio/                   rendered MP3s
  covers/                  album artwork
```

## Notes

- No audio is bundled from any third party — everything is generated by this repository.
- Album artwork was created for this project.
- The app is client-only; opening `dist/index.html` without a server will not work,
  because ES modules need to be served over HTTP.
